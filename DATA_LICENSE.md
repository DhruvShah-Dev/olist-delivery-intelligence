# Data attribution and use

This project analyzes the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/olistbr/brazilian-ecommerce/home/). Olist publishes that dataset under [Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-nc-sa/4.0/). Credit: Olist.

The source CSVs are not included in this repository. The aggregate CSVs in `outputs/`, chart images in `assets/`, and data-derived content in the report and dashboard are adaptations of the Olist dataset. Use and share these materials under the dataset license, including its attribution, noncommercial, and share-alike conditions. This project is independent and is not endorsed by Olist.

The Python source code is separately licensed under MIT; see `LICENSE-CODE`. That code license does not change the terms of the source data or its adaptations.
